== Scope of support

Community support is provided on a best-effort basis by volunteers through the link:mailing-lists.html[mailing lists] and https://github.com/apache/shiro/discussions[GitHub Discussions].
Commercial support is offered by third parties such as Flow Logix and Yupiik, see link:commercial-support.html[Commercial Support].
Defects are tracked in https://github.com/apache/shiro/issues[GitHub Issues], and security vulnerabilities are reported privately as described on the link:security-reports.html[Security Reports] page.

[#supported-versions]
== Supported versions

[cols="1,3",options="header"]
|===
| Release line | Support

| 3.x
| Supported. Receives security fixes.

| 2.x
| Receives only critical security fixes.

| 1.x
| End of life. No further releases or security fixes.
|===

Please use the most recent release of a supported line.
Fixes for older release lines that are out of scope for the open source project are available through link:commercial-support.html[commercial support].
When a release line stops receiving security fixes, the end of support is announced on the link:mailing-lists.html[mailing lists] and on the link:download.html[download page], and this table is updated.
Older releases remain available in the link:release-archive.html[release archive].

== Sponsorship

Sponsorship can be used simply as a way to say thank you for the work that has been done
or as a way to encourage specific issues to be worked on.
In either case, while the Apache Shiro project thanks you for your support,
we cannot be responsible for any promises and/or contributions made by an individual committer,
as individual commits must be reviewed and accepted by the project team.
