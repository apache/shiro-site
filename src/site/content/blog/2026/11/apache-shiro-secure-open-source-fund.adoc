= Apache Shiro joins the GitHub Secure Open Source Fund
:jbake-author: Lenny Primak
:jbake-date: 2026-11-18 00:00:00
:jbake-type: post
:jbake-status: published
:jbake-tags: blog, security

Apache Shiro is now part of the https://github.com/open-source/github-secure-open-source-fund[GitHub Secure Open Source Fund].
We are glad to be in the company of other widely used projects, and we are grateful to GitHub for supporting the security work that maintainers do.

== What the fund does

The fund pairs maintainers with funding, security education and direct access to security experts.
The goal is to help projects find and fix vulnerabilities before they reach the people who depend on them.

== The agentic security pilot

As part of the fund, GitHub, Microsoft Security and the GitHub Security Lab ran a pilot using Codename MDASH, Microsoft's multi-model agentic scanning harness.
The pilot scanned widely used open source projects for security vulnerabilities and worked with maintainers on the fixes.

The emphasis of the pilot is a good fit for our project.
Maintainers do not need more AI-generated bug reports.
They need fixes that are correct, reviewed and ready to merge.
Findings were coordinated with maintainers, so they could be triaged, discussed and shipped through each project's normal release process.

Read the full write-up, including the combined results across all five sessions of the fund and a video with feedback from participating maintainers, in the https://github.blog/open-source/maintainers/maintainers-dont-need-more-ai-bug-reports-they-need-fixes[GitHub blog post].

== What this means for Shiro users

Security reports for Shiro continue to follow the process described in our link:/security-reports.html[security policy], and fixes are announced through our usual advisories and releases.
Please keep your Shiro dependencies up to date, and see our link:/blog/2026/11/apache-shiro-security-advisories.html[recent security advisories post] for details on current fixes.

== Shiro still needs sustained support

The fund is a one-time contribution.
It helps us right now, but it does not pay for the ongoing work of reviewing reports, writing fixes, testing and shipping releases.
As we described in our link:/blog/2026/04/community-effort.html[community effort post], Shiro is maintained entirely by volunteers, and the project needs continuing support to stay healthy and secure.

If your organization depends on Shiro, please consider helping:

* Engage a company that offers link:/commercial-support.html[commercial support] for Shiro.
* Sponsor the maintainers directly on GitHub: https://github.com/sponsors/bmarwell[Benjamin Marwell] and https://github.com/sponsors/lprimak/[Lenny Primak].
* See our link:/support.html[support page] for more ways to give back.

== Thank you

Thank you to the GitHub Secure Open Source Fund team, the Microsoft Security and GitHub Security Lab teams, and the other maintainers in the program.
We look forward to continuing this work and making Shiro safer for everyone who builds on it.
